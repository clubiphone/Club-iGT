# Club iGT — GitHub Pages

Sitio estático adaptable a móviles. No requiere pagos, servidor ni compilación.

## Publicación desde iPhone

1. En Archivos, descomprime el ZIP descargado.
2. En Safari, entra en https://github.com/new e inicia sesión como `clubiphone`.
3. Crea un repositorio público llamado `club-igt` (opcional: marca Add a README).
4. Abre el repositorio y elige **Add file → Upload files**. Sube `index.html`, `styles.css`, `script.js` y `README.md`.
5. Dentro del repositorio, crea la carpeta `assets` (desde **Add file → Create new file**, escribe `assets/.gitkeep` y confirma). Luego entra en `assets` y sube `embajador.jpg` y `logo.png`.
6. En **Settings → Pages**, selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)** y pulsa **Save**.
7. La web aparecerá en https://clubiphone.github.io/club-igt/ después de unos minutos.

**Nota:** Si Safari oculta botones, toca `aA` o el menú de página y solicita **Sitio web de escritorio**.

## Edición

Colores y curvas: `styles.css`. Textos, secciones y enlaces: `index.html`. Menú móvil: `script.js`.

El enlace de Facebook es provisional y debe sustituirse por el enlace real. Los elementos gráficos de las tarjetas son ilustraciones CSS, no fotografías de equipos específicos.
